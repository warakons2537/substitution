# WL Substitution System — ระบบจัดการสอนแทน บ้านวังลึก (ย.น.)

เว็บแอป HTML/JS บน GitHub Pages + Supabase (โปรเจกต์เดียวกับ WL Admin · ใช้บัญชี Login ชุดเดียวกัน)

**ระบบลาของครู + ระบบสอนแทน** — แจ้งลา · ทะเบียนการลา (โควตา/คงเหลือ) · จัดครูสอนแทน · บันทึกการสอนแทน · สรุปรายครู · ใบลาและรายงาน A4/Excel/Word
หน้าตาและโครงเมนูเหมือน WL Admin (สีแดงเลือดหมู-ทองเป็นของแอปนี้) · ทดสอบตรรกะ: `node tests/leaves.test.mjs`

## ติดตั้ง (ครั้งแรก)
1. Supabase → โปรเจกต์ของ WL Admin → SQL Editor → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → Run
   (สร้างเฉพาะตาราง `sub_*` ไม่แตะตารางของ WL Admin · รันซ้ำได้)
2. อัปโหลดไฟล์ทั้งหมดใน repository ใหม่ (ให้ `index.html` อยู่ชั้นนอกสุด)
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save
4. เข้าเว็บด้วยบัญชีผู้ดูแลของ WL Admin → เป็นผู้ดูแลระบบสอนแทนอัตโนมัติ
5. เมนู "นำเข้าตารางสอน" → เลือกไฟล์สำรอง .json จาก WL Scheduler → บันทึก
6. เมนู "ผู้ใช้และสิทธิ์" → กำหนดสิทธิ์ (ผู้ดูแลระบบ / ฝ่ายวิชาการ / ผู้ขอลา) และผูกชื่อครูให้ผู้ขอลา

## เปลี่ยนโลโก้

`apple-touch-icon.png` (180×180) และ `logo-full.png` (ภาพเต็มในหน้า Login)

## อัปเดต 2569.10.31-4 (แยก 2 ระบบ · สิทธิ์หลายหน้าที่ · อนุญาตใบลา 2 แบบ · กระดิ่งแจ้งเตือน)
- **รัน `supabase/schema.sql` ซ้ำอีกครั้ง (รอบ 4)** แล้วเข้าเมนู "ผู้ใช้" กำหนดหน้าที่ให้แต่ละคนใหม่ (ผู้ที่เป็นผู้ดูแล/ฝ่ายวิชาการเดิมถูกย้ายให้อัตโนมัติ)
- แยกเป็น 2 ระบบ สลับที่แถบบน: **ระบบลา (งานบุคคล)** และ **ระบบสอนแทน (งานวิชาการ)** (+ ผู้ดูแลระบบ) แต่ละคนเห็นเมนูตามหน้าที่
  - ทุกคนที่ผูกชื่อครูแล้วเป็น "ครู": ยื่นใบลา ดูคำขอ/ประวัติลาของตัวเอง ดู "สอนแทนของฉัน" และสรุปของตัวเอง
  - หน้าที่เสริม (เลือกได้หลายอย่างต่อคน): ผู้ดูแลระบบ · ฝ่ายวิชาการ · งานบุคคล · ผู้อำนวยการ
- **ฝ่ายวิชาการไม่เห็นเหตุผลการลา/ที่ติดต่อ/ใบรับรองแพทย์** — บังคับที่ฐานข้อมูล (ปิดสิทธิ์อ่านคอลัมน์ `reason`,`contact` ของ `sub_requests` · ทะเบียนการลาเห็นได้เฉพาะงานบุคคล/ผอ./เจ้าตัว · ฝ่ายวิชาการอ่านข้อมูลการลาผ่านฟังก์ชัน `sub_leave_public` ที่ไม่มีเหตุผล)
  - ถ้าเพิ่มคอลัมน์ใหม่ใน `sub_requests` ต้อง `grant select (คอลัมน์)` ให้ `authenticated` ด้วย
- **การอนุญาตใบลา 2 แบบ** ตั้งที่ "ตั้งค่าการลา" (งานบุคคล): "มีผลทันที" (ค่าตั้งต้น) หรือ "ต้องอนุญาตในระบบ (ผอ. กดอนุญาต)" ตั้งรายประเภทได้ · ใช้คู่กับการเซ็นกระดาษ: งานบุคคลกด "ตรวจแล้ว/เซ็นแล้ว" ที่หน้า "ตรวจ/อนุญาต"
- การจัดสอนแทนไม่รอการอนุญาต · สถานะใบลาไม่ผูกกับการจัดสอนแทนครบหรือไม่อีกต่อไป
- **กระดิ่งแจ้งเตือนในแอป** (Realtime + โพลทุก 60 วินาที): ใบลาใหม่/รออนุญาต → งานบุคคล/ผอ. · คิวสอนแทนใหม่ → ฝ่ายวิชาการ · ผลอนุญาต → ครูผู้ลา · ถูกจัดให้สอนแทน → ครูผู้สอนแทน · ข้อความไม่ใส่เหตุผลการลา
  - ต้องเปิด Realtime ให้ตาราง `sub_notifications` (SQL พยายามเพิ่มเข้า publication `supabase_realtime` ให้แล้ว ถ้าไม่สำเร็จจะใช้โพลแทน)
- ยังไม่มี: Web Push (ทำเป็นขั้นถัดไปหลังทดสอบกระดิ่ง) · LINE (ไม่ทำตามที่ตกลง)
