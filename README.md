# WL Substitution System — ระบบจัดการสอนแทน บ้านวังลึก (ย.น.)

เว็บแอป HTML/JS บน GitHub Pages + Supabase (โปรเจกต์เดียวกับ WL Admin · ใช้บัญชี Login ชุดเดียวกัน)

## ติดตั้ง (ครั้งแรก)
1. Supabase → โปรเจกต์ของ WL Admin → SQL Editor → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → Run
   (สร้างเฉพาะตาราง `sub_*` ไม่แตะตารางของ WL Admin · รันซ้ำได้)
2. อัปโหลดไฟล์ทั้งหมดใน repository ใหม่ (ให้ `index.html` อยู่ชั้นนอกสุด)
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save
4. เข้าเว็บด้วยบัญชีผู้ดูแลของ WL Admin → เป็นผู้ดูแลระบบสอนแทนอัตโนมัติ
5. เมนู "นำเข้าตารางสอน" → เลือกไฟล์สำรอง .json จาก WL Scheduler → บันทึก
6. เมนู "ผู้ใช้และสิทธิ์" → กำหนดสิทธิ์ (ผู้ดูแลระบบ / ฝ่ายวิชาการ / ผู้ขอลา) และผูกชื่อครูให้ผู้ขอลา

## เปลี่ยนโลโก้
อัปโหลดรูปทับไฟล์ใน `img/` โดยใช้ชื่อเดิม: `logo-32.png`, `logo-64.png`, `logo-192.png`, `logo-512.png`,
`apple-touch-icon.png` (180×180) และ `logo-full.png` (ภาพเต็มในหน้า Login)

## อัปเดต 2569.10.31-2 (เฟส 2: ทะเบียนการลาของครู)
- **ต้องรัน `supabase/schema.sql` ซ้ำอีกครั้ง** (เพิ่มตาราง `sub_leaves`, `sub_leave_types`, `sub_holidays`, ฟังก์ชัน `sub_leave_days`, trigger ซิงก์คำขอ → ทะเบียน, คอลัมน์ `sub_users.staff_id`) — รันซ้ำได้ ไม่ลบข้อมูลเดิม และนำเข้าคำขอลาเดิมเข้าทะเบียนอัตโนมัติ
- เมนูใหม่ "ทะเบียนการลา" (ครูเห็น/บันทึกของตัวเอง → สถานะ "รอตรวจ" · ฝ่ายวิชาการ/ผู้ดูแลบันทึกแทนทุกคนและกด "บันทึกแล้ว" · ลบได้เฉพาะผู้ดูแลระบบ)
  - บันทึกการลาได้โดยไม่ต้องมีการสอนแทน · ลาครึ่งวัน · ใบรับรองแพทย์ · สรุปรายครู/รายประเภท · ยอดใช้ไป/คงเหลือตามโควตา · แจ้งเตือนเมื่อเกินโควตา
  - นับวันลาเป็นวันทำการ (จ.–ศ.) หักวันหยุดที่ตั้งไว้ (ประเภทที่ตั้งเป็น "นับวันปฏิทิน" เช่น ลาคลอด นับทุกวัน)
  - คำขอลา/ขอสอนแทนที่ส่งใหม่จะลงทะเบียนให้อัตโนมัติ และสถานะตามคำขอ
- เมนู "ตั้งค่า": แท็บ "ประเภทและโควตาการลา" และ "วันหยุด" (**ค่าโควตาตั้งต้นเป็นเพียงตัวอย่าง ตรวจสอบกับระเบียบก่อนใช้**)
- ใบลา: ช่อง "ลามาแล้ว/ลาครั้งนี้/รวมเป็น" ใช้ข้อมูลจากทะเบียน (หักวันหยุดแล้ว)
- ประเภทการลาเพิ่ม: ลาพักผ่อน · ลาไปช่วยเหลือภริยาที่คลอดบุตร · ลาอุปสมบท/ลาไปประกอบพิธีฮัจย์
- หมายเหตุ: ลาเฉพาะบางคาบ จะนับเป็น 1 วัน — ผู้ดูแลแก้เป็นครึ่งวันได้ในทะเบียน
